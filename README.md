# 데이터 구조 1

데이터 구조 1 과목의 과제, 퀴즈, 실습 C 코드 백업입니다.

| 폴더 | 내용 |
|---|---|
| `CODE/과제/` | 행렬, 계산기, 교과서 예제, 퀴즈 등 초반 과제 |
| `CODE/기말/` | 연결 리스트, 큐, 리스트로 구현한 큐, 수식 트리, 리포트 과제 |
| `데이터 구조/` | 과제, 기말, 큐(스택), 트리 실습 |

- Visual Studio 솔루션 단위로 저장되어 있어 각 폴더의 `.sln` 또는 `.c` 파일을 열어 빌드합니다.
- `x64/`, `Debug/`, `.vs/` 등 Visual Studio 빌드 산출물(`.obj`, `.pdb`, `.ilk`, `.tlog`)이 함께 커밋되어 있습니다.
